# 怎么写一关

改一个文件：`public/levels.js`。网址是自动派生的，你只写答案。

## 三条规则

1. **网站第一道门（全局第 2 关）固定在 `/`**（同学打开站点就是它；第 1 关在洛谷上，不在本站）。
2. **第 N+1 关的网址 = `/' 第 N 关的首个答案 '/`**
   —— 所以第 2 关的答案是「狂奔在沙漠中暴雨下」，第 3 关的网址就是 `/狂奔在沙漠中暴雨下/`。
3. **最后一关的答案不构成网址**，它直接通往揭晓页。

也就是说：`answers[0]`（每关的第一个答案）同时是"这一关的钥匙"和"下一关的网址"，
后面的 `answers[1]`、`answers[2]` 只是宽松判定用的备选写法，不影响网址。

## 判定方式

同学的输入**归一化后含有**本关任意一个答案就算通过。归一化 =
全角转半角（NFKC）+ 去掉所有空白 + 转小写。

所以「狂奔在沙漠中暴雨下」「狂奔在沙漠中暴雨下 」「我今天听到的是狂奔在沙漠中暴雨下」
「狂奔 在沙漠中 暴雨下」都会通过。

## 加一关 / 换一关：完整示例

假设你要加一关：答案是「雨停之后去看海」，密文用 Base64 藏一段视频号。

**第 1 步 · 想好答案，先检查它能不能当网址**

```bash
node tools/url.mjs "雨停之后去看海" --host https://你的域名
```

```
密钥：雨停之后去看海
归一化：雨停之后去看海
站内路径：/%E9%9B%A8%E5%81%9C%E4%B9%8B%E5%90%8E%E5%8E%BB%E7%9C%8B%E6%B5%B7/
完整链接：https://你的域名/%E9%9B%A8%E5%81%9C%E4%B9%8B%E5%90%8E%E5%8E%BB%E7%9C%8B%E6%B5%B7/
```

答案里**不要有空格、`/`、`?`、`#`**（会把网址切断或让链接不可靠）；`url.mjs` 会提醒你。

**第 2 步 · 生成密文**

```bash
node tools/cipher.mjs base64 --text "BV1qh4y1x7Zk"        # → QlYxcWg0eTF4N1pr
node tools/cipher.mjs vigenere --text "BV1qh4y1x7Zk" --key lcr   # → MX1hs4a1o7Km
node tools/cipher.mjs caesar --text "BV1qh4y1x7Zk" --shift 4
```

可用的方式：`caesar` / `vigenere` / `railfence` / `morse` / `base64` / `reverse`。
想确认自己能解回来，就加 `--decode` 反着跑一遍。
**写完一定要自己解一次**，别把解不开的密文发出去。

**第 3 步 · 写进 levels.js**

```js
{
  title: '关卡名（页面上显示的主标题）',
  face: '题面文字（可选；和 cipherText 至少有一个）',
  cipherText: 'QlYxcWg0eTF4N1pr',
  answers: ['雨停之后去看海'],
  hints: ['那句暗示范畴的谜面', '第二条（点名手法）', { image: '/images/example.png' }, '最后一条（直接给答案）'],
  // demo: true,   ← 只影响 check.mjs 的"待替换"提醒，页面上不会显示任何角标；内容替换完把这行删掉
},
```

加一关就把新对象插在 `levels` 数组里；删一关就删掉对象。中间插入也没关系，
网址会按新顺序重新派生。

**`hints`（必填，至少一条）** 就是页面下方的「给一条提示」按钮：点一次给一条，已经给出的**留在页面上不消失**，
一条条往下追加，给完按钮就变灰。数组顺序 = 从含蓄到直白的递进顺序。

**`face`（可选）** 是显示在标题下面的**题面文字**（第三关的 `lhy` 是当密文放的，所以没用它）。
`cipherText` 和 `face` **至少要有一个**，否则卡片上什么谜面都没有。没写 `cipherText` 的关卡，密文框会自动隐藏。

**提示项可以是图片**：在 `hints` 里写 `{ image: '/images/gate-3.webp' }`（文件放进 `public/images/`），
点到这一条时才会把图片显示出来——适合"看图猜字"这种要逐步揭图的谜题。也可以写成
`{ text: '看图', image: '/images/gate-3.webp' }`，让文字和图片同时出现。
图片建议用 WebP 压一下（第三关那张原图 1.1 MB，压成 832px WebP 后只有 71 KB，肉眼无差别）。
`check.mjs` 会检查图片文件是否存在，`tools/verify-deploy.mjs` 会检查线上图片能不能取到。

卡片上**不再单独显示谜面**——`hints[0]` 就是谜面，所以第一条要写成"看不懂密文时希望有人说的那句话"。
不写 `hints`（或写成空数组）会被 `check.mjs` 直接报错。

**`title` 就是页面上的主标题**：「第 x / y 关」那行的下面就是它，同时也会出现在浏览器标签页标题
和 `check.mjs` 的输出里。

**第 4 步 · 自检 + 试玩**

```bash
node tools/check.mjs --allow-demo     # 看链路空跑对不对
node tools/serve.mjs                  # 打开 http://127.0.0.1:8788/ 自己点一遍
```

内容全写完后必须跑 **不加 `--allow-demo`** 的 `node tools/check.mjs`，它会因为还有
`demo` 标记或示例文字而报错——这是防止你带着占位内容发布的保险。

## 生日信正文

同一个文件底部的 `reveal`：

```js
export const reveal = {
  title: '生日快乐',
  paragraphs: ['第一段……', '第二段……'],
  signature: '—— 你的署名',
  images: [],                       // 想放照片就写 ['/photos/1.jpg']
};
```

照片放进 `public/photos/`，然后写 `/photos/1.jpg`（以 `/` 开头，保证在任何密钥网址下都能加载）。
`images` 留空就是纯文字信。不要用外链图片——哪天链接挂了，信就有了缺口。

## 第 2 关现在用的是什么

- 密文：`FZ1bj4c1h7ab`
- 手法：凯撒 +4（字母后移四位，数字原地不动）→ 解开是 `BV1xf4y1d7wx`
- 谜面：就是 `hints` 的第一条（点「给一条提示」时最先出现的那句）

想换手法：把 `cipherText` 换成新密文、`hints` 的第一条跟着改成对应暗示即可。
注意**改第 2 关的答案会连带改掉第 3 关的网址**（自动跟随，不用手工改别处），
但真实世界里那个视频里说的话是固定的，所以第 2 关的答案一般不动。

## 几条容易踩的坑

| 现象 | 原因 |
|---|---|
| 下一关打不开、跳回"打不开任何一道门" | 上一关的 `answers[0]` 里有空格或 `/` |
| 两关莫名其妙串在一起 | 两关的 `answers[0]` 相同或互相包含，`check.mjs` 会报撞车 |
| 随便打几个字就过了 | 某个答案太短（1 个字），`check.mjs` 会提醒 |
| 发布后满页"打不开任何一道门" | `public/404.html` 被加进去了，删掉它（它会关掉 Pages 的 SPA 回退） |
| 同学提前剧透 | 站点是公开的、题库是明文的，别把真正敏感的内容放进去 |
| 第 2 关被提前剧透 | 前两条提示别出现答案或视频号；第 3 条起是故意给的梯子，所以 `BV...`/答案出现在 `hints` 里是正常的 |

## 想彻底不给源码看

现在的判定是"输入含有明文答案"，所以答案必然写在 `levels.js` 里。
如果哪天你想让源码里连答案都看不到，只需要改 `public/shared/levels-utils.js` 里的
`answerMatches` / `matchedAnswer`：改成"显示只存答案的 SHA-256，输入哈希后严格比对"，
网址继续用答案本身（网址不需要在配置里出现）。代价是同学必须一字不差。
`tools/check.mjs` 用的是同一份判定函数，改完它会立刻告诉你链路还通不通。
